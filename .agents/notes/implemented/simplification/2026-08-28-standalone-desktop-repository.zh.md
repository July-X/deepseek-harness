# Agent Note：桌面外壳由独立仓库独占维护

Status: implemented

[English](2026-08-28-standalone-desktop-repository.md) | 中文

## 问题

桌面外壳拥有独立的 Tauri 源码、前端、发布工作流和运行时依赖策略。它与插件型 Harness 仓库同时维护会形成第二条所有权路径，也会让根级检查依赖另一个发布仓库的产品。

## 决定

桌面外壳唯一由 [July-X/dsh-xlink](https://github.com/July-X/dsh-xlink) 维护。本仓库不包含桌面源码树、桌面发布工作流或桌面专属 CI 断言。独立仓库负责 Tauri 源码、管理面板、资源、文档、测试和发布配置。

## 已考虑的替代方案

**在两个仓库保留同步副本。** 两份副本需要持续同步并可能发生分叉，所有权仍然不明确，因此不采用。

**在本仓库保留转发包装或发布工作流。** 包装或工作流仍会让本仓库承担桌面职责，并使根级 CI 继续依赖独立应用的文件，因此不能形成单一所有者。

## 后果

桌面功能修改和发布检查在独立仓库中完成。本插件型 Harness 仓库的根级 CI 和文档只覆盖留在这里的包和应用。归档的[桌面外壳实现记录](../../archived/feature/2026-08-21-tauri-desktop-shell.md)保留实现依据，不作为当前源码归属说明。
